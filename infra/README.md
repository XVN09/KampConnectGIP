# Infra

Alles om KampConnect op een server te draaien: compose-bestanden en de configuratie van de servers
en de reverse proxy. Geheimen horen hier niet; die staan in de omgevingsvariabelen van de server.

Lokaal alle services starten gebeurt niet hier, maar met de Aspire AppHost in
`backend/800 - Hosting/KampConnect.Hosting.AppHost`.
