# Packages

Gedeelde Dart-code voor de apps in `apps/`, bv. de API-client (gegenereerd uit `api/`), modellen en het thema.
Apps en packages koppel je met een pub workspace: een `pubspec.yaml` in de root van de repository
die alle Dart-projecten opsomt.

Deze map heeft enkel zin als ook de webfrontends in Flutter komen. Anders hoort gedeelde code in
`apps/mobile` en mag deze map weg.
